# AgenticAG

## Cursor Cloud specific instructions

- Install: `npm install`
- Tests: `npm test`
- Typecheck: `npm run typecheck`
- Dev server: `npm run dev` (binds `0.0.0.0:3000`)
- Live Grok voice, chat, and TTS need `XAI_API_KEY` in `.env.local`. Without it the UI still loads and shows a banner.
- Voice mode must be tested with headphones on a machine that can grant microphone permission.
